## Для чего эта игра

«Лесоруб» создан для поддержки реабилитации и тренировки людей с протезами рук.
Одна из задач при освоении мышечного управления протезом — научиться отдельно
напрягать мышцы-сгибатели и разгибатели, не включая обе группы одновременно.
Игра переносит эту тренировку в задачу с понятной визуальной обратной связью.

Игрок рубит дерево, выбирает сторону удара и избегает веток. Один мышечный канал
отвечает за левую сторону, другой — за правую. На экране отображаются уровни
обоих сигналов и настраиваемые пороги. Так можно наблюдать активацию нужного
канала и лишнее напряжение противоположного. Таймер задаёт постепенно
ускоряющийся ритм; предусмотрены комбо и сохранение личного рекорда.

В этой публичной сборке можно попробовать механику **тапами, мышью или клавишами
1/2**, без оборудования. Для тренировки по реальным мышечным сигналам требуется
отдельное подключение совместимого источника данных: веб-страница сама по себе
не устанавливает связь с протезом. Это экспериментальный дополнительный
инструмент, не замена индивидуальной программе реабилитации и не заявление
о клинически подтверждённой эффективности.

## Управление

- На телефоне — тап слева или справа **по всему игровому полю под HUD и до
  поверхности земли**. Верхние шкалы и счёт, сама земля и нижние кнопки не рубят.
  В Web тапы включены по умолчанию; в Android их можно включить переключателем
  «ТАП ПО ЭКРАНУ».
- На компьютере — **1 / 2**, в том числе NumPad, или клики при включённых тапах.
- Шестерёнка справа внизу — пауза и настройки. «ЗВУК» и «МУЗЫКА» независимы.
- Шкалы показывают сигналы, светлые засечки меняют пороги; «СМЕНА» меняет стороны.

Геймплей вдохновлён Timberman, реализация — Godot 4 с русским интерфейсом.

## Установка кнопкой в главном меню

На GitHub Pages в главном меню есть кнопка **«УСТАНОВИТЬ»**. В Chrome/Edge и
других поддерживающих браузерах она открывает системный install prompt, когда
браузер разрешил установку. Событие установки не вызывается автоматически.
Если prompt недоступен, кнопка показывает инструкцию для текущего браузера.

**Safari на iPhone не предоставляет программный install prompt**: там кнопка
открывает шаги «Поделиться → На экран „Домой“». В уже установленном PWA кнопка
скрыта. В itch.io iframe её нет — установка доступна по прямой ссылке Pages.

Игровая область на Pages — **540×960 CSS-пикселей по центру** с пустыми полями
по бокам. На маленьком экране она целиком уменьшается с сохранением 9:16,
без обрезания. Android и адаптивный iframe itch.io этим ограничением не меняются.

## PWA на iPhone — бесплатно, без App Store

1. Откройте **[прямую ссылку игры](https://one-zero-eight.github.io/hackathon-motorika-timberman-web/)**
   в **Safari**. Дождитесь полной загрузки и сообщения «Игра сохранена для запуска
   без интернета».
2. Нажмите **Поделиться → На экран «Домой» → Добавить**. Если есть переключатель
   «Открывать как веб-приложение», включите его.
3. Откройте новую иконку **онлайн** и снова дождитесь готовности офлайн-кэша:
   iOS может использовать отдельное хранилище для установленного приложения.
4. После этого проверьте холодный запуск в авиарежиме.

На Android/компьютере можно использовать «Установить приложение» в меню
совместимого браузера. Mac, Apple Developer и подписанный IPA для PWA не нужны.

**Для установки PWA нужна именно прямая ссылка GitHub Pages**, а не внешняя
страница itch.io с игрой в iframe. itch.io остаётся альтернативой для игры онлайн.
Ссылка itch.io не содержит секретного ключа: если автор ещё не открыл страницу
публично, она может быть недоступна посетителям.

## Android APK

Откройте **[последний релиз](https://github.com/one-zero-eight/hackathon-motorika-timberman-web/releases/latest)**
и скачайте `lesorub-arm64.apk`. Требуется **Android 7.0+ и ARM64**.
Установите скачанный APK; Android может запросить разрешение установки для
браузера/файлового менеджера. Приложение не опубликовано в Google Play.

Это release-режим движка с **тестовой подписью**, не публикационная подпись
магазина. Около 18 MiB: облегчённый движок без 3D/Vulkan. 32-битные устройства
этой сборкой не поддерживаются. Контрольная сумма — в файле `SHA256SUMS` релиза.

## Офлайн, обновления и звук

Service worker сохраняет всю веб-сборку, включая WASM/PCK. Новая версия
предлагает кнопку **«Обновить»**, а не прерывает активный раунд. Для получения
обновлений нужен интернет; без сети работает последняя закэшированная версия.
Браузер может удалить кэш и рекорд при очистке данных или нехватке места — тогда
загрузите игру онлайн ещё раз. Переустановка APK для обновления PWA не требуется.

Звук разблокируется после касания игрового экрана. Если на iPhone тихо, проверьте
громкость, Silent Mode и оба выключателя в игре. В сборке исправлена потеря
выхода WebAudio из-за динамического создания аудиошин Godot 4.7.2.

Нужны WebAssembly и WebGL 2. Используется Compatibility без потоков и без
требования COOP/COEP/SharedArrayBuffer. Работа на конкретном iPhone/Safari требует
проверки на устройстве: автоматические тесты Chromium не заменяют эту проверку.
